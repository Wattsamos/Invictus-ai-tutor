# AI Data Science Tutor

This is AN AI Power tutor that helps nstudents learn 
Data Science and AI engineering concepts.
## Current Features
- Accepts Student questions
- Generates AI responses
- Uses a pretrained language model
- Uses a custome prompt

## How to Run

1. Create Virtual environment:
python-m venv .venv

Activate it:
.venv\Scripts\activate

Install dependencies:
pip install -r requirements.txt

Run:
python app.py
